## Как запустить

1. Клонируйте репозиторий:
```bash
git clone <URL_вашего_репозитория>
cd Flutter_Lab2
```
2. Перейдите в папку основного проекта:
```bash
cd first_flutter_app
```
3. Установите зависимости:
```bash
flutter pub get
```
4. Запустите приложение в Chrome:
```bash
flutter run -d chrome
```
